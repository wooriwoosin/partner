# 구글시트 `업체관리` 탭 — 컬럼 안내

시트에서 직접 일괄 수정하실 때 보는 문서입니다.
앱은 컬럼을 **"이름"으로 찾아 읽습니다.** 열 순서를 바꾸거나 열을 옮겨도 안전하고,
컬럼 **이름만 그대로 두면** 됩니다. (이름을 바꾸면 그 항목은 앱에서 안 보입니다)

## 계약상태는 어떻게 정해지나 (계약 탭 필터·칩)

시트에 `계약상태` 컬럼은 **없습니다.** 아래 순서로 자동 판정합니다.

1. `계약제외` = Y → **제외**
2. `위탁판매`=Y **그리고** `개인정보`=Y → **완료**
3. 둘 중 하나만 Y → **진행중**
4. `계약서발송` = Y → **발송대기** (보냈고 서명 기다리는 중)
5. 아직 안 보냈는데 이번 주 개통 실적 있음(`최근개통일`) → **⚠️ 확인필요** (발송 독촉 대상)
6. `위탁판매`가 비어 있음 → **정보없음**
7. `계약비고`에 "만료" 글자 포함 → **만료**
8. 그 외 → **미진행**

## 일괄 수정 팁

- **Y/N 항목**은 대문자 `Y` `N`으로 넣어주세요 (`y`/`예`/`O`는 인식 안 됨).
- **빈칸과 `N`은 다릅니다.** 빈칸 = "아직 확인 안 함", `N` = "확인했고 아님".
  계약상태 "정보없음"은 `위탁판매`가 빈칸일 때입니다.
- `업체명`을 바꾸면 개통리스트 업로드 시 **다른 업체로 인식**될 수 있습니다.
  이름이 바뀐 업체는 `소속원문`도 같이 맞춰주세요.
- 행을 지우는 것보다 `상태`를 `휴면`으로 두는 편이 안전합니다 (기록·이력 유지).
- 수정 후 앱에서 **[새로고침]** 을 눌러야 화면에 반영됩니다.

## 시트정리() — 옛 컬럼 청소 (1회 실행)

예전 버전에서 쓰던 컬럼이 남아 있으면 Apps Script 편집기에서 `시트정리` 함수를 실행하세요.

- 실행 전 `업체관리_백업_날짜시각` 탭으로 **원본을 자동 복사**합니다.
- 제거 대상: `웹활용` `직접접수` `접수대행` `유선접수전달` `유선개통전달` `무선개통전달` `회신전달` `대표아이디`
- `웹접수`/`웹회신`이 비어 있으면 옛 `전달마커`·`웹활용` 값으로 채운 뒤 제거하므로 **정보가 사라지지 않습니다.**
- 남은 컬럼을 위 표 순서대로 재배치합니다.

## 저장했는데 시트에 반영이 안 될 때 — `진단()`

Apps Script 편집기에서 **`진단()`** 함수를 실행하면(시트는 전혀 안 바뀝니다)
실행로그에 아래 항목이 나옵니다.

- **중복 헤더** — 같은 이름의 열이 두 개면 저장이 엉뚱한 열로 갑니다
- **id 가 빈 행** — 중간에 빈 행이 있으면 그 아래 업체 저장이 한 칸씩 밀립니다
- **중복 id** — 저장은 위쪽 행에만 되고, 화면에는 아래 행이 보일 수 있습니다
- 없는 컬럼 / 시트 크기 / 코드버전

셋 다 `없음 ✔` 이면 시트 구조는 정상이고, 원인은 브라우저 캐시 쪽입니다
(직원 PC에서 **Ctrl+Shift+R** 로 강력 새로고침).
