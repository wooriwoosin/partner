# 업체 통합 관리앱

거래처(판매점 / 협력점 / 자점)의 **기본정보 + 계산서방식 + 전자계약**을
하나의 화면·하나의 DB로 관리하는 웹앱입니다.

- **프론트엔드(HTML/JS)** : 이 GitHub 저장소만 사용 (GitHub Pages 로 서빙 — Apps Script 에는 HTML 없음)
- **메인 DB** : Google Sheets `협력점 관리` — `업체관리` 탭
  (`1shhA5RdXP7DiaMIyR33bTG2jFj4SFqumYflY0lF0pwc`)
- **연결 다리** : 시트에 붙는 얇은 Google Apps Script **JSON API 전용** (`apps-script/Code.gs`)
- 기존 ②계산서방식 / ③전자계약서 시트는 **참고용 소스** — `병합실행()` 1회로 데이터만 메인 DB로 가져옵니다.

```
[GitHub Pages 정적 HTML]  ── fetch ──▶  [Apps Script JSON API]  ──▶  [메인 DB: 업체관리 탭]
                                              ▲ 병합실행() 1회
                        [② 계산서방식 시트]  [③ 전자계약서 시트]  (읽기만, 수정 안 함)
```

---

## 분류 규칙 (자동 판정)

소속(E열) **앞 기호**로 업체구분을, 사원명(B열) **괄호 마커**로 전달여부를 판정합니다.

| 앞 기호 | 업체구분 | 소통채널 | 비고 |
|---|---|---|---|
| `■ ■■ □ □□` | **판매점** | 카카오톡채널 | 웹활용 X(일부 제외), 모든 요청 대신 전달 |
| `★ ★★ ☆ ☆☆` | **협력점** | 카카오톡단체방 | 전달여부는 마커(O/X)로 결정 |
| `◆ ◆◆ ◇ ◇◇` | **협력점(인센티브)** | 카카오톡단체방 | 별도 인센티브 업체, 마커 규칙 동일 |
| 숫자 `0.~9.` 접두 | **자점** | 어드민 | 영업정산/시흥영업팀/천안영업팀 등 |
| 앞머리 `●` | **자점** | 어드민 | 우주커넥트·케이티텔레캅 충북지사·패스앤슈팅 |

**전달마커(사원명 괄호)** — 협력점에 적용
- `(O) (○) (o)` → **전달** (단체방으로 대신 전달)
- `(X) (x)` → **미전달** (업체가 직접 웹 접수/처리)
- `(?)` → **보류** (이번 정리 대상, 상태=보류로 표시)

전달 기본값(수정 가능):

| 구분 / 마커 | 웹활용 | 접수대행 | 유선접수 | 유선개통 | 무선개통 | 회신 |
|---|---|---|---|---|---|---|
| 판매점 | N | Y | Y | Y | Y | Y |
| 협력점 (O) | N | Y | Y | Y | **Y** | Y |
| 협력점 (X) | Y | N | N | N | **Y** | N |
| 협력점 (?) / 무기호 | – | – | – | – | **Y** | – (보류) |
| 자점 | Y | N | N | N | N | N |

> **무선개통전달은 O/X와 무관하게 판매점·협력점 항상 Y** (요구사항 11).
> 자동값은 어디까지나 "기본 세팅"이며 업체별로 화면에서 개별 수정할 수 있습니다.

현재 파일 기준 자동분류 결과: **총 482개 업체** (자점 13 · 판매점 241 · 협력점 228, 보류 55).

## 처음 설정 (1회)

### 1) Apps Script 배포 → 웹앱 URL 만들기
1. [구글시트](https://docs.google.com/spreadsheets/d/1shhA5RdXP7DiaMIyR33bTG2jFj4SFqumYflY0lF0pwc/edit) 열기 → **확장 프로그램 › Apps Script**
2. `apps-script/Code.gs` 내용을 붙여넣기 (기존 코드 삭제 후)
3. 상단 함수 목록에서 `setup` 선택 → **실행** (권한 승인). `업체관리` 탭이 생성됩니다.
4. **배포 › 새 배포 › 유형: 웹 앱**
   - 실행: **나(소유자)**
   - 액세스: **모든 사용자** (GitHub 정적 페이지에서 호출하려면 필요)
5. 나온 **웹앱 URL**(`https://script.google.com/macros/s/.../exec`) 복사

### 2) 프론트엔드에 URL 연결
`assets/config.js` 를 열어 붙여넣기:
```js
window.APP_CONFIG = {
  API_URL: 'https://script.google.com/macros/s/여기에_붙여넣기/exec',
  WRITE_TOKEN: '',   // Code.gs 의 WRITE_TOKEN 을 설정했다면 동일하게
  ...
};
```
> `WRITE_TOKEN` 은 선택. 공개 배포 시 무단 쓰기를 막고 싶으면 `Code.gs` 와 `config.js` 양쪽에 같은 값을 넣으세요.

### 3) GitHub Pages 켜기
저장소 **Settings › Pages › Source: `Deploy from a branch`** → 이 브랜치 / `root` 선택.
잠시 후 나오는 주소로 접속하면 앱이 뜹니다.

### 4) 초기 데이터 넣기
앱 우측 상단 **[시트에 초기데이터 넣기]** 클릭 → 자동분류된 482개 업체가 시트에 들어갑니다.
(또는 `data/seed.csv` 를 시트에 직접 붙여넣어도 됩니다.)

### 5) ②③ 데이터 병합 (1회)
계산서방식·전자계약서 시트의 데이터를 메인 DB로 가져옵니다.
1. Apps Script 편집기에서 함수 목록의 **`병합실행`** 선택 → **실행**
2. 완료 로그: `병합 완료: 총 N개 업체 | ② 매칭.. | ③ 매칭..`
3. 메인 DB 시트의 **`병합리포트`** 탭에서 확인 필요 항목 검토
   - `신규추가(②/③)` : 메인 DB에 없어 새로 추가된 업체 (구분 확인)
   - `중복의심` : 같은 이름 2회 이상 (예: ③의 김용균 2행)
   - `연락처상이` : 메인 DB와 ③의 연락처가 다른 업체
- 매칭 규칙: 업체명 정규화(기호 `■★☆◆□`·마커 `○●◎`·공백 제거) + 옛이름 치환(`천안모바일→누네띠네중고폰`, `show예산→쇼예산`)
- 지점형 업체(옆커폰 각 지점, 신에이치엠 각 지점)는 **각각 개별 업체 행**으로 유지 (각자 정산)
- ②③ 원본 시트는 읽기만 하고 수정하지 않습니다. 재실행해도 안전하지만, 병합 후 화면에서 수정한 계산서/계약 값이 원본 값으로 되돌아갈 수 있으니 **1회 실행을 권장**합니다.

## 사용법
- **탭 3개**: `기본 정보`(전달 체크리스트) · `🧾 계산서`(형태/수신방법/발송규칙) · `📝 전자계약`(계약①②/사업자등록증/제외)
- **상단 통계 카드** 클릭 → 구분/보류/계산서형태로 바로 필터 (탭에 따라 카드가 바뀜)
- **검색·필터**(전달마커·웹활용·상태·계산서형태)로 원하는 업체만 보기 — 검색은 대표자 이름도 포함
- **+ 신규 업체** → 소속 원문 입력 후 **[자동채우기]** 하면 구분/전달값이 자동 세팅 → 필요시 수정 후 저장
- 각 행 **[수정]** → 한 모달에서 기본정보 + 계산서 + 계약 정보를 모두 편집
- 업체는 계속 추가·변동되므로 화면에서 바로 관리하면 시트에 반영됩니다.

## 데모(읽기전용) 모드
`API_URL` 이 비어 있으면 `data/seed.json` 을 읽어 화면만 확인할 수 있습니다(저장 불가).
배포 전 미리보기용입니다.

  styles.css          스타일

## 통합 현황
- ✅ ② 계산서방식 / ③ 전자계약서 → 병합(앱의 [②③ 데이터 병합] 버튼)으로 메인 DB에 통합 (계산서·전자계약 탭)
- ✅ ④ 정산내역서 가공앱 v6 → `settle.html` 로 통합. 메인앱에 로그인해 두면 메인 DB의 계산서형태를 자동으로 불러옴 (내장 DB는 fallback)
- ✅ 개통리스트 엑셀 업로드 → 신규 업체 자동 등록 (중복 자동 제거)
- 기존 ②③ 앱스크립트의 HTML 화면은 더 이상 사용하지 않음 (화면은 이 저장소가 유일)
- navergg.kr 자동 동기화(로그인→지난주 개통 신규 협력점 자동추가)는 이후 단계로 보류 (GitHub Actions 크론 예정)

## 엑셀에서 seed 다시 만들기
새 `전체사원관리` 엑셀을 받으면:
```bash
python3 tools/build_seed.py "<엑셀경로>.xlsx"
```
`data/seed.json` / `data/seed.csv` 가 갱신됩니다. (openpyxl 필요: `pip install openpyxl`)
