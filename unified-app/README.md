# 업체 통합 마스터 (통합앱)

협력점 관리(①) · 업체별 계산서방식(②) · 전자계약서(③) — 세 구글시트를
**하나의 마스터 시트 + 하나의 웹앱**으로 통합하는 도구입니다.

- 병합은 Apps Script가 **사장님 구글 계정 안에서 직접** 세 시트를 읽어 수행합니다. (데이터 이동/다운로드 없음)
- 지점이 많은 업체(옆커폰 각 지점, 신에이치엠 각 지점 등)는 **각각 개별 업체 행**으로 유지됩니다. (각자 정산하므로)
- 기존 ①②③ 시트는 **건드리지 않습니다.** 정산내역서 가공앱(④)은 계속 ② 시트를 읽어 동작합니다.

## 배포 순서 (5분)

1. [sheets.new](https://sheets.new) 로 **새 스프레드시트** 생성 → 이름: `업체 통합 마스터`
2. 메뉴 **확장 프로그램 → Apps Script**
3. 기본 `Code.gs` 내용을 지우고 이 폴더의 **`Code.gs`** 붙여넣기
4. **+ → HTML** 로 `Index` 파일 생성 → 이 폴더의 **`Index.html`** 붙여넣기 → 저장(💾)
5. 스프레드시트로 돌아가 **새로고침(F5)** → 상단에 **[통합관리]** 메뉴가 생김
6. **[통합관리 → 1. 소스 3개 병합 실행]** 클릭
   - 처음 실행 시 권한 승인 창 → 계정 선택 → "고급 → 이동" → 허용
   - 완료되면 `마스터` 시트(전체 업체)와 `병합리포트` 시트가 생성됨
7. **병합리포트 시트 확인**: 신규추가/중복의심/연락처상이 항목을 한번 훑어보고 필요하면 마스터에서 수정
8. Apps Script 화면에서 **배포 → 새 배포 → 웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **Google 계정이 있는 모든 사용자** (또는 조직 정책에 맞게)
   - 배포 → 생성된 URL이 통합 관리앱 주소

## 웹앱 기능

| 영역 | 내용 |
| --- | --- |
| 통계 카드 | 총 업체 / 판매점·협력점·자점 / 정발행·역발행·원천세 / 계약 완료 수 |
| 전체 탭 | 모든 업체 목록 (구분·법인·계산서형태·상태 필터 + 통합 검색) |
| 계산서 탭 | 계산서형태가 있는 업체만 — 형태·수신방법·비고 중심 |
| 계약서 탭 | 계약 정보가 있는 업체만 — 계약①② / 사업자등록증 / 제외 여부 |
| 행 클릭 | 상세 모달에서 기본·업무전달·계산서·계약 정보 한 번에 수정 |
| 신규 업체 | 우상단 버튼으로 추가 (id 자동 부여) |
| 삭제 | 소프트 삭제 — 행을 지우지 않고 상태만 `삭제`로 변경 |

## 병합 규칙

- 매칭 키: **업체명 정규화** (기호 ■★☆◆□ / 마커 ○●◎ / 공백 제거, 소문자화)
- 옛이름 자동 치환: `천안모바일 → 누네띠네중고폰`, `show예산 → 쇼예산`
- ①에 없고 ②/③에만 있는 업체 → 신규 행 생성 + 리포트에 `신규추가` 기록 (구분은 기호로 추정: ■판매점 / ★협력점)
- 같은 이름 2회 이상 → 첫 행만 반영 + `중복의심` 기록 (예: ③의 김용균 2행)
- ①과 ③의 연락처가 다르면 → 값은 ① 유지 + `연락처상이` 기록
- 병합 재실행 시 마스터가 초기화되므로(수기 수정 유실) 경고 후 진행

```
[연락]   대표자 | 연락처 | 소통채널 | 대표아이디 | 계정수
[업무]   웹활용 | 직접접수 | 접수대행 | 유선접수전달 | 유선개통전달 | 무선개통전달 | 회신전달 | 인센티브 | 전달마커
[계산서] 계산서형태 | 수신방법 | 계산서비고
[계약]   계약서1 | 계약서2 | 사업자등록증 | 계약제외 | 계약비고
[관리]   비고 | 출처(①②③) | 수정일시
```
