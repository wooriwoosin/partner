# 협력점 동기화 도구 (로컬 실행)

navergg.kr 어드민에 로그인 → **고객관리 › 전체고객관리**에서 **개통일 · 지난주** 개통건을 받아,
**아직 등록 안 된 신규 협력점**을 자동 분류해 구글시트(`업체관리`)에 추가하는 도구입니다.
사장님 PC에서 실행되며, **아이디·비밀번호·인증번호는 이 PC 밖으로 나가지 않습니다.**

```
[로컬 폼(ui.html)]  →  [Playwright 로그인·수집]  →  [지난주 개통 엑셀]  →  [기존 대조·자동분류]  →  [구글시트]
```

동작 검증 완료(오프라인 부분): 파싱 → 신규/변경 감지 → 분류. 로그인/화면 이동 **선택자만 실제 페이지로 확정하면** 됩니다.

---

## 설치 (최초 1회)
필요: **Node.js 18+** (https://nodejs.org 에서 설치)

```bash
cd partner-sync
npm install          # playwright, xlsx 설치 (+ 크로미움 자동 설치)
cp config.example.json config.json
```

`config.json` 편집:
- `API_URL` : 앞서 배포한 Apps Script 웹앱 URL (프론트 config.js 와 동일)
- `LOGIN_URL` : navergg.kr 로그인 페이지 주소
- `headless` : `false` 권장(화면이 보여야 캡차/인증 대응 가능)

## 실행
```bash
npm start
```
브라우저에서 **http://localhost:4180** 접속 →
1. 아이디 / 비밀번호 입력
2. **휴대폰 인증번호 사용** 체크박스 — OTP 없이 로그인되는 계정은 **체크 해제**
3. **미리보기(반영 안 함)** 로 먼저 확인 → 이상 없으면 **동기화 실행**

로그인 흐름은 요청하신 그대로입니다:
`아이디·비번 입력 → [아이디인증] 클릭 → (선택)인증번호 → [로그인]`

## 매주 하는 일
- 새 협력점이 **지난주 첫 개통** → 자동 감지·추가
- 기존 업체가 **★ → ■** 처럼 기호가 바뀜 → **"기호 변경 감지"** 로 표시(자동 덮어쓰지 않고 확인용으로 보여줌)

---

## ⚠️ 지금 필요한 것 — 선택자 확정용 자료 2가지
제가 실제 페이지를 볼 수 없어, 아래를 주시면 **로그인/화면이동 선택자**를 실제 값으로 확정하겠습니다.

1. **로그인 페이지 HTML 소스**
   navergg.kr 로그인 화면에서 마우스 우클릭 → *페이지 소스 보기* → 전체 저장(또는 복사).
2. **전체고객관리 페이지 HTML 소스** + **지난주 개통 엑셀 샘플 1개**
   (개통일·지난주로 조회한 뒤 받은 실제 엑셀 파일)

받으면 `lib/sync.js` 의 `DEFAULT_SELECTORS` 와 `lib/parseActivations.js` 의 컬럼 매핑을 확정하고,
`config.json` 의 `selectors`/`excelColumns` 예시도 채워 드립니다.

> 그때까지 로그인/네비게이션 선택자는 **임시값**이라 실제 로그인은 아직 안 됩니다.
> 파싱·대조·분류·시트반영 로직은 이미 검증됐습니다.

---

## 보안
- 자격증명은 폼 입력 → 로컬 서버(localhost) 로만 전송, **디스크 저장 안 함**.
- `config.json` 은 `.gitignore` 처리되어 저장소에 올라가지 않습니다.
- 채팅/코드에 비밀번호를 넣지 마세요. (이미 노출된 비번은 교체 권장)

## 파일
```
server.js                 로컬 서버(폼 서빙 + /sync)
ui.html                   입력 폼 + 실행로그 + 결과표
lib/sync.js               Playwright 로그인·수집 (선택자 확정 대상)
lib/parseActivations.js   개통 엑셀 파싱 (컬럼 확정 대상)
lib/diff.js               신규/기호변경 감지
lib/classify.js           분류 엔진(프론트·seed 와 동일 규칙)
lib/sheet.js              Apps Script API 읽기/쓰기
config.example.json       설정 템플릿 (복사해서 config.json 로)
```
